# JobTrack - Job Application Tracker CRUD

A Vue 3 + Vite CRUD application based on the provided To-Do CRUD reference project.

## Features
- Create job applications
- Read/display job applications
- Update/edit applications
- Delete applications
- Search applications
- Filter by status
- Dashboard statistics
- LocalStorage persistence
- Responsive dark/purple UI

## Run

```bash
npm install
npm run dev
```

The application stores job application data in the browser's LocalStorage under `jobApplications`.
